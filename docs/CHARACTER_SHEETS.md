# Редактор персонажа и пользовательские листы

В разделе «Персонажи» доступны «Создать персонажа», «Свой лист» и «Загрузить JSON».

## Создание

По умолчанию открыт «Лист целиком»: происхождение, уровень и подкласс, характеристики и поправки, владения, снаряжение, заклинания, собственные блоки и сохранение. Верхняя сводка пересчитывается при редактировании. Навигация прокручивает к разделу. Кнопка «По шагам» возвращает последовательное заполнение.

Уровень можно задать сразу при создании. Для добавленных уровней по умолчанию используются средние кости хитов, максимум можно скорректировать. Выбор подкласса проверяется относительно класса и уровня. Бонусы происхождения/черт не применяются автоматически — их нужно внести в поля поправок.

## Свой лист

Конструктор добавляет к листу D&D до 120 блоков: текст, число, отметка и счётчик. Можно изменить заголовки, порядок, ширину блока и число колонок. Это пользовательская часть листа D&D, а не новый движок правил для произвольной игровой системы. Поля не исполняют формулы и не меняют автоматические расчёты.

Шаблон скачивается отдельным JSON (`format: dnd-companion-sheet`, `version: 1`) и загружается в другого персонажа. Он включает текущие значения собственных блоков, но не имя, аккаунт и базовые параметры героя. Перед заменой заполненных блоков требуется подтверждение.

После создания персонажа значения редактируются в блоке «Мой лист», кнопка «Сохранить свои поля» записывает изменения. Настройка структуры доступна через «Редактировать» → «Свой лист». Счётчики не восстанавливаются автоматически при отдыхе. Пользовательские блоки входят в печать и полный лист общего лобби; не помещайте туда секреты мастера.

## Импорт и экспорт JSON

- Собственный формат: `format: dnd-companion-character`, `version: 1`, `data` — данные персонажа. Сохранены совместимость с прежним экспортом `{id,version,data,...}` и импорт объекта CharacterData. Лимит файла — 8 МБ; ссылки на справочники должны быть доступны в текущей редакции.
- Long Story Short: документ `jsonType: character`, `version: "2"`, `data` — JSON-строка. Лимит исходника — 1 МБ. Поддерживается основной класс с уровнями, базовые характеристики, навыки, дополнительные спасброски, хиты, монеты, текстовые блоки, оружие текстом и обычные числовые ресурсы. Класс, вид и предыстория сопоставляются однозначно по именам; при несовпадении выберите соответствия вручную. Редакция должна совпадать с выбранной в приложении.

В LSS эффекты, формулы, мультикласс, дополнительные бонусы, слои расчётов, связи заклинаний и часть специальных полей **не преобразуются автоматически**. В частности, максимальные хиты берутся из базового поля hp-max, которое не всегда равно итоговому значению в LSS; формула КД не исполняется. Сверьте боевые показатели и перенесите нужные поправки. Заклинания, подкласс и предметы для автоматической механики выбираются из наших справочников. Импорт сообщает эти ограничения перед сохранением, исходный JSON сохраняется и скачивается владельцем отдельной кнопкой. Исходник не включается в ответ API лобби игрокам.

Загрузка проходит через предпросмотр и редактор. Только кнопка создания записывает новый лист в текущий аккаунт. Импорт не перезаписывает персонажей по ID из файла и сохраняет текущие/временные хиты; сервер повторно проверяет данные и права. Повторная загрузка создаёт ещё одну копию.

Схема и пример LSS изучены по [официальной документации формата](https://longstoryshort.app/doc/developers/characters/). Совместимость относится к указанному формату, а не ко всем возможным расширениям LSS.

Проверка 10 ноября 2026: автоматические тесты native/legacy/LSS, шаблонов и серверного импорта; в браузере — создание персонажа со счётчиком, сохранение, скачивание JSON, обратная загрузка, предпросмотр и создание отдельной копии. Использована отдельная тестовая база.

## Бумажный лист и свободный шаблон

Вкладка «Бумажный лист» показывает светлый лист с рамками, характеристиками и модификаторами, навыками, спасбросками, боевыми параметрами и разделами снаряжения и магии. Она открывается по умолчанию. «Экспорт PDF / печать» открывает этот же макет; в системном окне печати выберите «Сохранить PDF». Формат — A4. Длинный лист продолжается на следующих страницах. JSON персонажа доступен рядом и сохраняет полную структуру своего листа.

«Настроить свой лист» → «Шаблон: полный лист D&D» создаёт редактируемую копию текущих значений. Можно менять или удалять любые поля, в том числе шесть характеристик, добавлять собственные числа, текст, отметки и счётчики, изменять тип поля, подпись, раздел, порядок и ширину. Максимум — 120 полей. «Пустой шаблон» очищает поля после подтверждения. Флажок «Использовать вместо стандартного листа» включает свободный макет для просмотра, PDF и лобби. Снятие флажка возвращает стандартный лист, сохраняя свои поля.

Свободный лист — ручной документ: его значения не синхронизируются с механикой D&D и не пересчитывают друг друга. Изменение Силы в свободном листе не меняет автоматические броски во вкладке «За столом». Стандартные данные персонажа сохраняются для возврата к обычному режиму. Для создания записи персонажа по-прежнему требуется выбрать базовый класс, вид и предысторию.

Значения своих полей редактируются во вкладке «Свои поля» и сохраняются кнопкой. Структура меняется через «Настроить свой лист» с последующим сохранением персонажа. Скачать и загрузить шаблон можно внутри конструктора; шаблон включает значения полей, поэтому перед распространением удалите личные заметки.
